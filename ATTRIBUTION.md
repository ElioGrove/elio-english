# Vocabulary source

The vocabulary ordering is derived from the public `kajweb/dict` repository,
which is the word-resource repository linked by `SteveSuv/remix-words-funny`.

- Upstream application: https://github.com/SteveSuv/remix-words-funny
- Word-list source: https://github.com/kajweb/dict
- Imported fields: headword, original order, phonetic fallback, part-of-speech fallback,
  and one short Chinese meaning fallback.
- AI study content is generated independently at first use and stored in D1.

The importer intentionally excludes upstream example sentences, exams, memory
notes, speech URLs, and full dictionary records.
