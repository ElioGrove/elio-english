## 已修复

| 问题 | 原因与修复 |
| --- | --- |
| 单词发音错误 | React 点击事件被当成朗读文本。显式传入 headword，并优先选择英语语音；发音失败有提示。 |
| 状态切换卡住 | 保存进度后等待下一词的 AI 生成，期间锁定全部操作。切词与生成分离，先显示基础词义，AI 请求不锁定学习操作。 |
| 失败仍显示新状态 | 保存前直接修改状态、缺少异常处理。现在确认保存成功后再更新，失败保留原状态并提示。 |
| 快速切词内容错位 | 上一请求可以覆盖当前单词。增加导航序号、请求取消及结果归属检查。 |
| 请求无限等待 | 浏览器普通请求 15 秒、生成请求 55 秒超时；Worker 上游请求 45 秒超时，可重试。 |
| 模型切换 | 默认使用 qwen3.8-flash，关闭深度思考，配置、生成类型、演示和文档同步。历史有效缓存保留，支持手动重新生成。 |
| 未学习统计错误 | 显式标回未学习的 progress 记录原来被扣除。现在仅扣除已学会和学习中。 |
| 今日计划不准确 | 改为 UTC+8 日界线，仅统计标为学习中或已学会的不同单词。 |
| 空按钮 | 实现上一词浏览历史、学习中词库分页和搜索快捷键，移除无对应功能的“继续阅读”按钮。 |
| 搜索不匹配提示 | 支持中文释义与英文前缀、空结果和失败提示，取消旧搜索，转义 LIKE 特殊字符。 |
| 刷新回到第一词 | 使用本机存储恢复最近词书及单词；演示模式不会覆盖真实学习位置。 |
| 异常数据导致白屏 | 校验 AI 嵌套数组元素及缓存；拒绝不完整结果。限制实际请求流大小，校验整数参数。 |
| 服务故障被误报配置缺失 | 生产启动错误区分服务/网络异常与安全配置缺失。 |
| 弹窗键盘操作缺失 | 增加 Escape 关闭、焦点循环与关闭后焦点恢复。 |
| 发布检查不完整 | 手动部署工作流先构建，再执行类型、应用回归和 Sites 兼容测试。 |

## 环境问题与后续边界

1. **本地千问凭据返回 401 / invalid_api_key**。已验证请求发往配置中的北京 DashScope 兼容地址。需要有效且与地域匹配的 Key 才能验收真实 AI 内容。生产 Cloudflare Secret 独立，本次没有读取或替换它，不能据本地失败判断生产凭据无效。
2. 发音使用设备的 Web Speech 英语语音。已验证文本与语言选择，音质仍由设备语音包决定；未进行人工听音验收。
3. 当前仍是单人密码站点。学习位置是本机恢复，学习状态保存在 D1。跨设备位置同步、用户账户、每日目标编辑及词库管理不在本次修复范围。
4. 词库 seed 依赖固定 ID，是原始导入和同一版本重复导入脚本。更新上游词书时需要另行设计按 normalized 关联的迁移，不能把重新生成的 seed 当成通用词库升级方案。
5. 尚未加入跨请求的 AI 生成锁；多标签同时生成同一个未缓存单词可能发生重复模型调用。现有页面内操作有取消和防重复提交保护，但不保证上游对已发出的请求停止计费。

模型参数参考：[百炼 OpenAI 兼容接口](https://help.aliyun.com/en/model-studio/qwen-api-via-openai-chat-completions)。本地运行验证参考：[Cloudflare 本地开发](https://developers.cloudflare.com/workers/local-development/)。
